# homerepair.samcbarth.com (Fix It Notes)

Affiliate-funded DIY home repair site in the samcbarth.com network. Shared rules: `C:\SamSites\NETWORK.md`.

Plain static HTML generated by `build.py` (Python 3, no dependencies; `make_og.py` needs Pillow). GitHub Pages serves the repo root from `main`.

## What is here

- 30 repair guides in 6 category hubs (plumbing, electrical, walls and tile, doors and windows, appliances, outdoor)
- Basic home toolkit buying guide (`/basic-home-toolkit/`)
- 3 calculators: paint coverage, tile/flooring, mulch/gravel (`/calculators/`, logic in `assets/calc.js`)
- News section "Fix It Notes Bulletin" at `/news/` with JSON Feed 1.1 at `/news/feed.json`
- About, Contact, Privacy, Terms, Affiliate Disclosure, 404
- `sitemap.xml`, `robots.txt`, `feed.xml` (RSS), `llms.txt`, `CNAME`

## Run locally

```
python build.py
python -m http.server 8825
```

Preview entry `homerepair` (port 8825) is in `.claude/launch.json` (and in `C:\.claude\launch.json` for the desktop app).

Check links: `python check_links.py` (internal) or `python check_links.py --external` (also hits every outside URL; cpsc.gov, esfi.org, whirlpool.com and a few others return 403 to scripts but load fine in a browser).

## Add content

Every page is generated from `content/`. Edit or add a file, then run `python build.py`.

- **Guide:** copy any file in `content/guides/` to `<new-slug>.json` and edit it. Fields: `category` (one of the slugs in `content/categories.json`), `summary` (the 1 to 2 sentence answer), `tools`/`materials` (each item's `q` is the Amazon search phrase; omit `q` for no button), `steps`, `safety`, `call_pro`, `faq`, `sources` (real URLs only), `related` (other guide slugs), optional `warnings` (`electrical`, `gas`, `ladder`, `structural`) and `calc` (a calculator slug).
- **News story:** add `content/news/<slug>.json` with `date`, `title`, `summary`, `body` (paragraphs), `why`, `source_name`, `source_url`, `tags`, `related` guide slugs. Every story must link a primary source; no copied text, at most one short attributed quote. The JSON Feed, RSS, sitemap and home page update on build.
- **Toolkit:** `content/toolkit.json`. **Static pages:** `content/pages.json`.

`build.py` warns on em dashes, banned hype words, and broken `related` slugs.

## Config ids (waiting on accounts)

All ids live in `config.json` (copied to `assets/config.js` on build). Empty values render nothing.

| Key | Status | Effect when set |
|---|---|---|
| `AMAZON_TAG` | Waiting on Amazon Associates approval | Appended as `&tag=` to every "Check price on Amazon" button. Buttons link to Amazon search results now, untagged. No prices or ratings are shown (Associates rules until the Product Advertising API unlocks after 3 sales). |
| `ADSENSE_CLIENT` | Not planned for launch (affiliate site), slot positions reserved | Renders ad slots after intro, mid-content and end of content. |
| `CONTACT_FORM_ID` | **Needs a HubSpot form in portal 20693956** | Embeds the form on `/contact/`. |
| `CONTACT_EMAIL` | Optional fallback | Shows a mailto button if no form id. |

Until `CONTACT_FORM_ID` or `CONTACT_EMAIL` is set, `/contact/` says the form is being set up. Fill one in before applying to Amazon Associates.

`ads.txt` lives at the root domain samcbarth.com (HubSpot), not here.
